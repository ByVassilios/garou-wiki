# Glossary

The words Garou use, as the mod uses them.

| Word | Meaning |
|---|---|
| Garou | Werewolves, in their own word |
| Gaia | The living world the Garou serve |
| The Wyrm | Corruption and destruction gone mad. See [The Wyrm](The-Wyrm.md) |
| The Weaver | Order and pattern. Its spirits are the pattern spiders |
| The Wyld | Raw change and growth |
| Tribe | One of the thirteen Garou peoples. See [Tribes, breeds and auspices](Tribes-Breeds-and-Auspices.md) |
| Breed | How a Garou was born: Homid (human), Lupus (wolf) or Metis (of two Garou) |
| Auspice | The moon a Garou was born under, and the role it gives |
| Homid, Glabro, Crinos, Hispo, Lupus | The five forms. See [Forms and shifting](Forms-and-Shifting.md) |
| Breed form | The form a Garou was born in |
| Rage | The wolf's fury |
| Gnosis | The tie to the spirit world |
| Willpower | Strength of will |
| Frenzy | The wolf taking over |
| The Thrall of the Wyrm | A frenzy that belongs to the Wyrm |
| Harano | A grief for the dying world |
| The Litany | The Garou's code. See [Frenzy, the Litany and Harano](Frenzy-and-the-Litany.md#the-litany) |
| Renown | Standing: Glory, Honor and Wisdom |
| Cub, Cliath, Fostern, Adren, Athro, Elder | The ranks, from 0 to 5 |
| The First Change | The first time a Garou takes the war form |
| Rite of Passage | The rite that makes a cub a Cliath |
| Gift | A power taught by a spirit |
| Rite | A ceremony led by a ritemaster |
| Ritemaster | The Garou who leads a rite |
| Moot | The sept's gathering at the full moon |
| Caern | A place of power the Garou have woken |
| Sept | The Garou who hold a caern |
| The Free Rangers | All the tribes together and their septs, under the name outsiders know |
| Pack | Garou bound to one totem |
| Totem | The spirit a pack or tribe follows |
| Ban | What a totem forbids its pack |
| Alpha | The pack's leader |
| Kinfolk | Humans and wolves of Garou blood who never Changed |
| The Delirium | The terror mortals feel at the sight of a Crinos |
| The Veil | The secret of what the Garou are |
| The Umbra | The spirit world |
| The Penumbra | The part of the Umbra next to the physical world |
| The Gauntlet | The wall between the worlds |
| Stepping sideways | Crossing the Gauntlet |
| Chiminage | What a spirit asks for a favor |
| Bane | A spirit of the Wyrm |
| Lune | A spirit of the moon |
| Fomor (plural fomori) | A person possessed and twisted by a bane |
| Black Spiral Dancers | Garou who fell to the Wyrm |
| Pentex | A corporation that serves the Wyrm |
| Fetish | An item with a spirit bound into it |
| Talen | A one-use item with a spirit in it |
| Klaive | A silver blade with a spirit in it |
| Leech | A vampire, to a Garou |
| Aggravated | A wound that doesn't regenerate |
